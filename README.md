# 007AI MiniMax 视频提示词优化

这是一个面向 MiniMax H3 / 海螺（Hailuo）的提示词优化 Skill。提供视频原稿、分镜脚本或参考图，即可将创意整理成一份 30 秒导演稿，由两段各 15 秒、可独立使用的视频提示词组成。

## 能做什么

- 按时间轴安排镜头、主体动作、机位和声音，明确第一段末镜如何接到第二段首镜。
- 保留原稿语言、必拍动作、主体特征和参考图编号，按需标注口播、字幕与后期叠加内容。
- 默认采用竖屏 9:16，可沿用用户指定的画幅。默认面向 MiniMax H3，旧版生成入口可按已知参数另行拆分。

交付物为文本提示词。视频生成和后期拼接由使用者在所选平台完成。

## 快速使用

1. 在支持 Skill 的助手中加载本仓库的 `SKILL.md`，并保留同级的 `references/` 目录。
2. 提供原稿、分镜或参考图，说明视频目标，以及必须保留的台词、动作、画幅或入镜限制。
3. 将两段提示词分别用于生成，并按成片顺序拼接。使用参考图时，在生成平台中关联对应素材。
